    Data sources, coordinate system & limitations ＋

    The model uses recorded shot locations and outcomes. It does not observe defensive pressure, player fatigue, injuries, or the circumstances of a future attempt. Location alone cannot capture every part of shot quality.

    Coordinates are centered at the basket. X is horizontal; positive Y points toward half court. Controls display feet, while the API accepts tenths of a foot. Shot value and zones are calculated by the server using NBA court geometry, including corner threes.

    Evaluation uses chronological game groups, separate validation and final test sets, and a constant-probability baseline. Check the selected bundle’s measurements before drawing conclusions about accuracy. Synthetic demo data is labeled and does not measure NBA performance.
